# Двор у пятиэтажек

Локация, собранная по фотографии: заросший двор между двумя кирпичными пятиэтажками, площадка, сарай с граффити, подстанция. Герой ростом 120 пикселей со снаряжением ходит по двору и взаимодействует с предметами.

Играть: откройте `index.html` (через GitHub Pages или любой веб-сервер).

## Файлы

| Файл | Что внутри |
|---|---|
| `page.html` | разметка страницы и стили; сборка подставляет сюда фото и код |
| `assets/photo.jpg` | исходная фотография двора |
| `build.json` | порядок склейки частей движка и игры |
| `src/decals.js` | рисунки на стенах, таблички, номера домов |
| `src/catalog.js` | каталог предметов: дома (окна в нишах, шторы, бельё), подъезды, площадка, деревья по породам, кусты, бурьян, трава по всему двору, клумбы из шин… |
| `src/map.js` | карта: строки земли (одна буква — метр) и список предметов |
| `src/instances.js` | превращение записей карты в предметы мира, провода, трава по всему двору (плитками 6 × 6 м, гуще у стен и бордюров) |
| `src/hero-state.js` | состояние героя, действия с предметами, команды |
| `src/dyn.js`, `src/dyn-items.js` | подвижные части: качели, банки, мяч |
| `src/update.js` | шаг мира |
| `src/pigeons.js` | голуби |
| `src/ui-*.js` | интерфейс: панель действий, портрет, инвентарь, разбор фото, схема, каталог |
| `src/boot.js` | запуск |

## Карта

Земля — строки символов: `.` газон, `,` бурьян, `:` вытоптанная земля, `#` асфальт, `_` бетонная отмостка. Предметы — список `{ type, at: [x, z], rot, … }`, где `type` — запись каталога.

Трава растёт сама: на каждой клетке газона и бурьяна, кроме тропинок и мест под предметами; у стен и бордюров — выше и с сухостоем, под деревьями — реже.
