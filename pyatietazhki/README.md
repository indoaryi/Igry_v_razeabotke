# Двор у пятиэтажек

Две локации, собранные по фотографиям: заросший двор между двумя кирпичными пятиэтажками (площадка, сарай с граффити, подстанция) и соседний двор с берёзами, где стоят два боевых костюма — ИБК-3 и «32» по эскизу игрока. Герой ростом 120 пикселей со снаряжением ходит по дворам, взаимодействует с предметами и может залезть в костюм. Время суток меняется: утро с туманом, день, золотой вечер, ночь с фонарями и светящимися окнами.

Играть: откройте `index.html` (через GitHub Pages или любой веб-сервер).

## Файлы

Двор собран на движке (`engine/`): дома, деревья, трава, машины, фонарь и лавочки — из его библиотеки предметов, костюмы — его шагающие машины. Здесь — только то, что есть у дворов и больше ни у кого.

| Файл | Что внутри |
|---|---|
| `page.html` | разметка страницы и стили; сборка подставляет сюда фото и код |
| `assets/photo.jpg`, `assets/photo2.jpg` | исходные фотографии дворов |
| `build.json` | порядок склейки частей движка и игры |
| `shots.json` | сценарии снимков для `tools/shoot.mjs` |
| `src/decals.js` | граффити на сарае, разметка щита |
| `src/catalog.js` | свои предметы первого двора: сарай с граффити и банками, игровой комплекс, качели, турник, горка, помост, баскетбольный щит |
| `src/catalog2.js` | что нужно двору с берёзами: золотые берёзы и рябина, осенняя трава, мигающие поворотники при сигнализации |
| `src/map.js`, `src/yard2.js` | карты двух дворов: строки земли (одна буква — метр), список предметов, машины, выходы, где солнце в какой час |
| `src/hero-state.js` | занятия героя во дворах (качели, турник, горка, башня), что можно сделать с каждым предметом, правила для сигарет и энергетика, стрельба по банкам |
| `src/dyn.js`, `src/dyn-items.js` | подвижные части: качели, банки, мяч — и как они попадают в кадр |
| `src/pigeons.js` | голуби (ночью сидят на крышах) |
| `src/inventory.js` | вещи в рюкзаке |
| `src/ui-*.js` | интерфейс: быстрые действия, портрет, инвентарь, разбор фото, схема, каталог |
| `src/boot.js` | запуск |

## Карта

Земля — строки символов: `.` газон, `,` бурьян, `:` вытоптанная земля, `#` асфальт, `_` бетонная отмостка. Предметы — список `{ type, at: [x, z], rot, … }`, где `type` — запись каталога.

Трава растёт сама: на каждой клетке газона и бурьяна, кроме тропинок и мест под предметами; у стен и бордюров — выше и с сухостоем, под деревьями — реже.
