# Движок

Общая основа для наших изометрических игр в пиксельном 2.5D. Вырос из «Двора у пятиэтажек» и растёт вместе с играми: сюда переезжает то, что нужно больше чем одной игре.

## Как он рисует

1. Всё в мире — 3D-модели, собранные кодом из простых форм: коробки, цилиндры, «лофты» из колец, многоугольники, линии в 1 пиксель.
2. Камера ортографическая, изометрия 2:1: метр по земле — 54 пикселя по диагонали клетки, герой ростом около 120 пикселей.
3. Сцена рисуется в низком разрешении («пиксели арта») и растягивается без сглаживания — отсюда пиксель-арт.
4. Свет ступенчатый: у каждого материала пять тонов (от тени к блику), шейдер выбирает тон, а узоры (кирпич, листва, окна, ржавчина…) рисуются прямо в шейдере по координатам модели.
5. Второй проход рисует контуры, затемняет стыки и подсвечивает предмет под пальцем. Номера предметов пишутся в отдельный буфер — по нему работает нажатие на предмет.
6. Земля — одна большая картинка, раскрашенная попиксельно по карте клеток. 3D-слой и эффекты (дым, искры, листья) кладутся поверх.

## Как устроен код

Части склеиваются сборкой (`tools/build.mjs`) в один скрипт внутри общей функции, в порядке из `build.json` игры. Поэтому все имена верхнего уровня общие — их нужно держать уникальными.

| Папка | Что внутри |
|---|---|
| `src/core/` | `prelude` (начало скрипта), `camera` (оси, масштаб, частота кадров), `math` (матрицы, векторы, шум) |
| `src/render/` | `materials` (пятитоновые палитры, `mat()`), `meshes` (формы), `webgl` (шейдеры, цели рендера, проход контуров, выбор предмета), `kit` (сборка предмета из частей и «запекание» в несколько сеток), `stage` (камера сцены, отбор видимого, сборка кадра) |
| `src/hero/` | `model` (герой и снаряжение), `skeleton` (кости и позы), `rig` (поза → кости → список того, что рисовать) |
| `src/world/` | `ground` (раскраска земли), `nav` (сетка проходимости, A*, спрямление пути) |
| `src/fx/` | `fx2d` (дым, вспышки, гильзы, искры, листья — поверх 3D) |

## Договорённости

- Единицы — метры. Мир: `x` вправо-вниз по экрану, `z` влево-вниз, `y` вверх. Клетка карты — 1 м.
- Материал: `mat('#цвет', { pat, b, p, r, noise, grain, spec, gloss })`. `pat` — номер узора в шейдере, `b` — второй цвет, `p`/`r` — параметры узора.
- Флаги у материала: `fl: 1` — без контура, `2` — активный предмет, `4` — мягкий контур (листва), `8` — становится прозрачным, когда заслоняет героя.
- Предмет строится в своей системе координат (начало — на земле, `+z` — его лицевая сторона) через `Kit`, затем запекается в мир.

## Сборка и проверка

```
node tools/build.mjs pyatietazhki          # собрать страницу
node tools/shoot.mjs shots far near all    # снимки сцены в безголовом браузере
```
