# Живой двор

Пиксельный двор, нарисованный одной картинкой и оживлённый на Phaser 3.80.

Чтобы поиграть, откройте `index.html` через любой веб-сервер (или через GitHub Pages).

## Что внутри

- **Смена дня и ночи.** Окна загораются и гаснут по своему расписанию, у подъездов горят лампы, светятся вывеска «ПРОДУКТЫ» и неон «ШАВЕРМА».
- **Погода.** Дождь с кругами на лужах, порывы ветра, падающие листья, качели раскачиваются от ветра.
- **Голуби.** Разлетаются от людей и собак, садятся на крыши и навесы, ночуют на крыше.
- **Жители по расписанию.** Мама с коляской, мужик с собакой, ребёнок, бабушка с авоськой, покупатели, ночной прохожий.
- **Глеб.** Ходит по тапу или с клавиатуры (WASD, стрелки), разговаривает с людьми, осматривает предметы.

## Как устроено

- `src/source.png` — исходная картинка.
- `tools/world_def.py` — разметка: где можно ходить, препятствия, заборы.
- `tools/build_assets.py` — собирает слои: убирает нарисованных прохожих, делает дневной и вечерний фон, вырезает окна и источники света.
- `src/sprites.js` — генератор пиксельных персонажей, голубей, собаки, коляски, зонтов.
- `src/game.js` — сама игра: навигация, время суток, свет, жители, погода, интерфейс, звук.
- `tools/assemble.py` — собирает итоговую страницу.
