# Пустая площадка

Самая маленькая игра на нашем движке: ни одного предмета, только земля, свет, время суток и герой. Здесь нет ни строчки кода дворов — значит, если площадка собирается и герой ходит, движок живёт сам по себе.

Играть: откройте `index.html` (через GitHub Pages или любой веб-сервер).

| Файл | Что внутри |
|---|---|
| `page.html` | страница: сцена, фишки, время суток, камера |
| `build.json` | только ядро движка и один файл игры |
| `src/lot.js` | карта 16 × 16 м (асфальт, бетон, газон, бурьян, тропинка), кнопки рук героя, запуск |
| `shots.json` | сценарии снимков для `tools/shoot.mjs --game=ploshchadka` |

Проверка зависимостей: `node tools/deps.mjs ploshchadka` — по всем пунктам должно быть «нет».
