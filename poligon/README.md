# Испытательный полигон

Своя локация на отвязанном движке: всё, что движок умеет, собрано в одном месте и ни одной строчки кода дворов. Внизу страницы — список возможностей с кнопкой «Показать»: она ведёт героя к нужному месту или переводит часы.

Играть: откройте `index.html` (через GitHub Pages или любой веб-сервер).

## Что где

- **Полигон** (36 × 28 м): общежитие-пятиэтажка с подъездами, машины у дома, бетонная площадка с двумя шагающими костюмами (ИБК-3 и «32»), подстанция и фонарь с проводами, огневой рубеж и пять мишеней, вышка с лампой у рубежа, контейнеры, бочки и блоки ФБС, будка КПП, щит у ворот, курилка с лавочками, роща в дальнем углу.
- **Опушка за воротами** (26 × 22 м): берёзы, ясени, клён, ива, кусты и бурьян, брошенный гараж и машина, листья на траве, низкое солнце справа.

## Файлы

| Файл | Что внутри |
|---|---|
| `page.html` | страница: сцена, панель «рядом», действия, снаряжение, время, камера, список возможностей |
| `build.json` | ядро движка, библиотека предметов, шагающие машины и четыре файла полигона |
| `src/catalog.js` | свои предметы полигона: мишень, вышка (высоты и ступени), контейнер, бочки, блоки ФБС, щит, будка КПП — и их рисунки |
| `src/map.js` | две локации: земля из прямоугольников, предметы, костюмы, выходы |
| `src/play.js` | мишени (падают от попадания), граната (свой предмет в руке и полёт), снаряжение, что можно сделать с каждым предметом |
| `src/boot.js` | быстрые действия, кнопки снаряжения, список возможностей движка, запуск |
| `shots.json` | сценарии снимков для `tools/shoot.mjs --game=poligon` |
