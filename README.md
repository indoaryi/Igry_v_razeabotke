# Игры в разработке

Здесь живут стратегии, которые мы делаем вместе с Claude.

## Проекты

- **Мир Девяти Земель** — пошаговая стратегия в духе классического Total War с детальным пиксель-артом.
- **Солнечная стратегия** — территориальная стратегия в стиле Terron.io по всей Солнечной системе.
- **Живой двор** (`dvor/`) — пиксельный двор с жизнью, сменой дня и ночи и погодой.
- **Тестовая новелла** (`vn-demo/`) — сцена «Двор под дождём».
- **Отсек 7** (`otsek/`) — сцена в духе классического Фоллаута: КПП у гермоворот.
- **Отсек 7 в изометрии** (`otsek-iso/`) — та же сцена в изометрии, персонажи и комната сделаны из 3D-моделей кодом.
- **Двор у пятиэтажек** (`pyatietazhki/`) — двор по фотографии в изометрии, герой со снаряжением. Первая игра на нашем движке и полигон для новых функций.
- **Испытательный полигон** (`poligon/`) — своя локация на движке без кода двора: общежитие, вышка у огневого рубежа, мишени, контейнеры, КПП, два шагающих костюма, за воротами опушка. Там же второй человек — прапорщик Сомов в защитном комплекте: разговаривает, ходит за героем, торгует. Внизу страницы — список всех возможностей движка с кнопкой «Показать».
- **Пустая площадка** (`ploshchadka/`) — самая маленькая игра на движке: только земля, свет и герой. Доказывает, что движок живёт без двора.
- **Новый большой проект** — в стадии дизайн-документа.

## Играть в браузере

Сайт: https://indoaryi.github.io/Igry_v_razeabotke/ — главная страница (`index.html` в корне) со списком всех игр. GitHub Pages публикует ветку `main` из корня как есть (`.nojekyll`), так что каждый пуш сам появляется на сайте через минуту-две. Включается один раз владельцем репозитория: Settings → Pages → Deploy from a branch → `main`, `/ (root)` → Save.

## Движок

`engine/` — общая основа для изометрических игр: 3D-модели кодом, отрисовка в пиксель-арт, свет, время суток, земля, навигация, герой. Ядро не знает об играх — они подключаются через крючки; рядом лежат библиотека предметов (дома, деревья, машины, фонари), шагающие машины и люди (другие персонажи, разговоры, следование, вещи и торговля). Как он устроен — в `engine/README.md`.

- Код — модули с явными связями: каждый файл перечисляет, что берёт у других, а вход игры `<папка игры>/src/main.js` — из каких модулей она состоит.
- Сборка игры в одну страницу: `node tools/build.mjs <папка игры>` (заодно `build/<папка игры>.dev.html` — игра прямо из модулей)
- Проверка модулей — без кругов, движок не зависит от игры, каждый импорт на месте: `node tools/deps.mjs <папка игры>` (с `--fix` сама допишет недостающие импорты)
- Игры сохраняются сами и продолжаются с того же места; ещё три слота и файл — в разделе «Сохранения» на странице игры
- Проверка переделок: `node tools/snap.mjs <папка> --game=<игра> --against=<снимки до>` (снимки совпадают до пикселя), сохранений — `node tools/test-saves.mjs <игра>`
- Снимки для проверки: `node tools/shoot.mjs <папка для снимков> --game=<папка игры>`
