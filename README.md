# Игры в разработке

Здесь живут стратегии, которые мы делаем вместе с Claude.

## Проекты

- **Мир Девяти Земель** — пошаговая стратегия в духе классического Total War с детальным пиксель-артом.
- **Солнечная стратегия** — территориальная стратегия в стиле Terron.io по всей Солнечной системе.
- **Живой двор** (`dvor/`) — пиксельный двор с жизнью, сменой дня и ночи и погодой.
- **Тестовая новелла** (`vn-demo/`) — сцена «Двор под дождём».
- **Отсек 7** (`otsek/`) — сцена в духе классического Фоллаута: КПП у гермоворот.
- **Отсек 7 в изометрии** (`otsek-iso/`) — та же сцена в изометрии, персонажи и комната сделаны из 3D-моделей кодом.
- **Двор у пятиэтажек** (`pyatietazhki/`) — двор по фотографии в изометрии, герой со снаряжением. Первая игра на нашем движке и полигон для новых функций.
- **Испытательный полигон** (`poligon/`) — своя локация на движке без кода двора: общежитие, вышка у огневого рубежа, мишени, контейнеры, КПП, два шагающих костюма, за воротами опушка. Внизу страницы — список всех возможностей движка с кнопкой «Показать».
- **Пустая площадка** (`ploshchadka/`) — самая маленькая игра на движке: только земля, свет и герой. Доказывает, что движок живёт без двора.
- **Новый большой проект** — в стадии дизайн-документа.

## Движок

`engine/` — общая основа для изометрических игр: 3D-модели кодом, отрисовка в пиксель-арт, свет, время суток, земля, навигация, герой. Ядро не знает об играх — они подключаются через крючки; рядом лежат библиотека предметов (дома, деревья, машины, фонари) и шагающие машины. Как он устроен — в `engine/README.md`.

- Сборка игры в одну страницу: `node tools/build.mjs <папка игры>`
- Проверка, что движок не зависит от игры: `node tools/deps.mjs <папка игры>`
- Снимки для проверки: `node tools/shoot.mjs <папка для снимков> --game=<папка игры>`
