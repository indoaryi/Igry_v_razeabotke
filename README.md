# Игры в разработке

Здесь живут стратегии, которые мы делаем вместе с Claude.

## Проекты

- **Мир Девяти Земель** — пошаговая стратегия в духе классического Total War с детальным пиксель-артом.
- **Солнечная стратегия** — территориальная стратегия в стиле Terron.io по всей Солнечной системе.
- **Живой двор** (`dvor/`) — пиксельный двор с жизнью, сменой дня и ночи и погодой.
- **Тестовая новелла** (`vn-demo/`) — сцена «Двор под дождём».
- **Отсек 7** (`otsek/`) — сцена в духе классического Фоллаута: КПП у гермоворот.
- **Отсек 7 в изометрии** (`otsek-iso/`) — та же сцена в изометрии, персонажи и комната сделаны из 3D-моделей кодом.
- **Двор у пятиэтажек** (`pyatietazhki/`) — двор по фотографии в изометрии, герой со снаряжением. Первая игра на нашем движке.
- **Новый большой проект** — в стадии дизайн-документа.

## Движок

`engine/` — общая основа для изометрических игр: 3D-модели кодом, отрисовка в пиксель-арт, свет, земля, навигация, герой. Как он устроен — в `engine/README.md`. Сборка игры в одну страницу: `node tools/build.mjs <папка игры>`, снимки для проверки: `node tools/shoot.mjs <папка для снимков>`.

## Как устроена работа

- Игрок и геймдизайнер: [indoaryi](https://github.com/indoaryi) — идеи, решения, плейтест.
- Код и графика: Claude.
- Каждое изменение сохраняется отдельным коммитом, так что любую версию можно вернуть.
